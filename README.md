# ScratchDrill
Scratchの理解度向上のためのドリル教材

## About
- プログラミング検定のように、実現したい挙動が出題され、それに合ったビジュアルプログラムを作成する。
- 漢字を使わずに制作する。

## 使い方
- 拡張機能つきプロジェクトが入った状態で Turbowarp を起動する。
    - URL内でこのプロジェクトの `./sb3/scratch3_drill.sb3` を指定し、呼び出す。
    - クエリパラメータで以下を指定する：   
        - studentId
        - studentName
    - リンクはこのようになる: https://turbowarp.org/editor?project_url=https://corekarakids.github.io/ScratchDrill/sb3/scratch3_drill.sb3&studentId=790&studentName=xxxyyy
- **サンドボックス環境を使わないことを許可**する。
- APIで問題セットを取得し、3問セットに取り組む。
    - APIキーで認証する。
- スタート画面から取り組むセットを選ぶ。
- 猫（ここにプログラムを書き込む）、テストランボタン、審査員、郵便受け（メッセージの受け取り用）の4つのスプライトが含まれている。

## API認証
- APIへ初めて接続するときに認証キーの入力画面が表示される。
- 入力したキーは、TurboWarpを開いているブラウザの `localStorage` に `scratchDrill.apiKey` という名前で保存される。2回目以降は保存済みのキーが自動的に使われる。
- APIリクエストには `X-LeON-Api-Key: <認証キー>` が付与される。
- APIが `401` または `403` を返した場合は保存済みのキーが削除される。ページを再読み込みすると新しいキーを入力できる。
- `localStorage` の内容は同じオリジンで動くJavaScriptから読み取れるため、第三者と共有する管理者用の秘密鍵ではなく、この用途専用の失効可能なキーを使う。

## 開発者の方へ
- ご自身を Collaborator に招待してください。
- プロジェクトを pull して、適当にブランチを切って開発してください。
- Turbowarp で複数ファイルを読み込むことができないため、1つの巨大なjsファイルになります。ご了承ください。
- 開発したものを [このリンク](https://turbowarp.org/editor?project_url=https://corekarakids.github.io/ScratchDrill/sb3/scratch3_drill.sb3) で使うには main ブランチにプッシュしなければなりません。テストする場合は、以下の手順を踏んでください。
    1. [Turbowarp エディタ](https://turbowarp.org/editor) を開く
    1. 「ファイル→コンピューターから読み込む」から `sb3/drill_no_ext.sb3` を読み込む \
        ※拡張機能が読み込まれた状態のsb3データには、その時点での拡張機能が焼き付いており、拡張機能の変更が反映されません。**拡張機能が含まれていないsb3**を使う必要があります。
    1. 左のメニューバーの最下部「拡張機能」から「カスタム拡張機能」を選択
    1. 開発中のjsファイルを選択またはドラッグ＆ドロップし、**「サンドボックスなしで実行」を選択**
        - URL内でクエリパラメータを `dev=true` とする
        - ローカルのhtmlを取得できるよう、Live Serverで http://localhost:5500 にアクセスできるようにしておく
        - さらにクエリパラメータを `api=false` とすると、API通信を使わず、ローカルの `dev_tools/questionObjects.json` から問題をロードできる（任意）
    1. 拡張機能ブロックを使ってスプライトを準備する \
        ※ここが煩雑なのでなんとかしたかったのですが、試行錯誤の末諦めました。**js更新のたびにスプライトの準備が必要になります。** devモードでは、Turbowarpの画面が現れてから**15秒の間に**以下の準備が必要です。
        - ネコ：「ここからかきはじめる」（任意：ここからかきはじめる(2) ）
        - テストラン：「このスプライトが押されたとき：テストランする」
        - パス：「このスプライトが押されたとき：パスする」
        - しんさいん：「このスプライトが押されたとき：こたえあわせをする」
        - ゆうびんうけ：拡張機能の使用はありません
    1. 動作確認
    1. ファイルを `./sb3/scratch3_drill.sb3` として**上書き保存**\
        ※`sb3/drill_no_ext.sb3` に保存しないように注意してください。 \
        ※これによって、拡張機能の内容もsb3に入ります。
- 開発した内容はコミットしたのちプルリクエストを送り、 GitHub 上の main ブランチに反映してください。
